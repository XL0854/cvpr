# 限定两周的实施边界

1. 普通网络：约 0.2M 参数，单侧 13×13 残余，先做单样本拟合，再做场景隔离开发训练。
2. 数据：现有三场景用于实现和开发；新增未使用的 kicker 验证、terrace 锁定测试。
3. 预计资源：两套 JPEG+深度压缩包约 1.4 GB；每对先离线冻结 RopStitch 初始网格和监督。
4. 停止条件：普通网络不能拟合单样本；跨场景多数图对不改善；或改善依赖覆盖下降/折叠。
5. 普通版本通过后才实现一个容量匹配的内容引导传播消融。

文献机制边界：REwarp 使用递归网络估计 homography 与 TPS，并用 Dirichlet 边界
控制孔洞/不连续；G1 连续性正则直接约束相邻局部切向共线；SENA 使用全局/局部
仿射、自由形变和基于视差一致性的 adequate zone/seam。拟议的候选机制只在
RopStitch 初始 13×13 残余分支中，用双视图内容调节相邻网格残余传播；在完成
容量匹配消融前不声称它与上述工作形成可发表的新颖差异。
