# ETH3D大视差正确对应诊断：courtyard小批量

## 问题与固定条件

本阶段检验“对应本身正确，但在RopStitch初始形变下残差较大”的匹配是否存在，以及常规筛选和保留这些点对几何的影响。原始Network和CoefNetwork冻结，alpha固定0.5；没有训练新网络。ETH3D深度、内外参只用于评价和D组选择，优化输入仍是两张RGB图像产生的候选对应。

## 真值与候选

- ETH3D courtyard原始畸变JPG、float32深度、THIN_PRISM_FISHEYE标定和位姿已验证。
- 官方相机公式的投影—逆投影闭环误差为1.56e-8 px。
- RoMa outdoor提交：`77f8d68803526dcddfd9b7a46bc76125bdc25f15`。
- 每对在512尺度取8 px规则网格，共4096个候选；不按置信度、循环误差、几何或RopStitch残差预筛。
- 5对共2,337个真值正确候选，其中1,450个初始画布残差≥10 px。

## 筛选诊断

在合并候选、约5%错误接纳率下：

| 规则 | 正确大残差保留率 | 正确小残差保留率 |
|---|---:|---:|
| 双向置信度 | 42.0% | 73.6% |
| 循环一致性 | 53.8% | 81.3% |
| 当前形变残差 | 0.0% | 69.1% |

固定的旧式组合规则（双向置信度≥0.5且循环误差≤2 px）错误接纳率8.9%，保留64.6%的正确大残差点和91.3%的正确小残差点。说明困难正确点确实更容易被常规可靠性规则漏掉，但常规规则并未完全失效；直接使用当前形变残差筛选才是明显失败项。

## A/B/C/D优化

固定参考侧，只更新目标侧13×13网格残差。各组使用相同150步Adam、鲁棒对齐损失、平滑/锚定/TPS雅可比约束和固定画布。源图8×8区域中`cell_id mod 4 == 0`的点仅用于最终评分，从不参与优化。

| 组 | 615个保留真值点平均画布误差 | 困难点平均误差 | 最大采样折叠率 | 最小重叠保留率 |
|---|---:|---:|---:|---:|
| A 原始RopStitch | 65.95 px | 96.32 px | 0 | 100% |
| B 当前残差筛选 | 65.65 px | 96.30 px | 0 | 99.8% |
| C 常规可靠性 | 53.55 px | 78.39 px | 0 | 90.2% |
| D 真值选择诊断 | 52.07 px | 76.32 px | 0 | 89.4% |

D相对A下降21.0%，说明正确候选能改善初始几何。D相对C只下降2.77%，并只在5对中的3对更好。B在3个困难图对上筛选后不足16点，无法产生更新。初始已对齐区域的平均误差为A 1.492 px、C 0.555 px、D 0.631 px；C对已对齐区域的保护略好。

## 判断

实测支持假设的前半部分：困难图对中存在大量正确大残差对应，按当前形变残差筛选会误伤它们，保留可靠对应能够改善几何。

当前证据不支持立即设计新筛选网络。常规双向置信度与循环一致性已经接近Oracle，D相对C的合并优势仅2.77%，同时D没有表现出更好的重叠覆盖或已对齐区域保护。按照预设判断条件，这属于“C接近D，当前切口创新空间有限”。

本结果来自单一场景、按难度选择的5对图像，不能估计自然数据中的发生频率，也不能证明跨场景泛化。下一步只进行独立场景复现；若D相对C仍小且不稳定，应停止该筛选方向。当前不进入网络训练。
